# راهنمای توسعهٔ درگاه برای سامانه نصر

از نسخهٔ ۱.۴.۰، درگاه‌ها مانند افزونه‌های مستقل وردپرس نصب می‌شوند. افزونهٔ درگاه باید پس از `plugins_loaded` یک نمونه از کلاس مشتق‌شده از `Nasr\Academy\Payment_Gateway` را با فیلتر زیر ثبت کند:

```php
add_filter('nasr_academy_payment_gateways', function ($gateways) {
    $gateways[] = new My_Nasr_Gateway();
    return $gateways;
});
```

شناسهٔ درگاه باید حداکثر ۲۵ نویسه و شامل حروف لاتین کوچک، عدد، خط تیره یا زیرخط باشد. متدهای ضروری:

- `id()`، `title()` و `description()` برای معرفی درگاه؛
- `fields()` برای تعریف تنظیمات سروری؛ فیلد محرمانه را با `secret => true` مشخص کنید؛
- `request($transaction, $context, $settings)` برای ایجاد درخواست و برگرداندن `redirect_url` و `provider_token`؛
- `verify($transaction, $callback, $settings)` برای تطبیق مبلغ/شناسه، فراخوانی تأیید وب‌سرویس و برگرداندن `success` و `reference`؛
- `availability()` در صورت نیاز به بررسی دسترس‌پذیری پویا پیش از نمایش درگاه.

اطلاعات محرمانه را در خروجی متدها، لاگ درخواست یا مرورگر قرار ندهید. مبلغ ثبت‌شدهٔ تراکنش را مبنا قرار دهید و هیچ مبلغی را مستقیماً از Callback نپذیرید. درج سابقهٔ مالی و جلوگیری از ثبت تکراری بر عهدهٔ هسته است.
